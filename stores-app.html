⚙ First-time setup required

To get started, you need to deploy the Google Apps Script backend and paste the URL here.

  1. Go to script.google.com → New project
  2. Paste the contents of stores-google-apps-script/Code.gs into the editor
  3. Replace YOUR_SPREADSHEET_ID_HERE with your Google Sheet ID
  4. Click Deploy → New deployment → Web app → Execute as Me → Anyone can access → Deploy
  5. Copy the web app URL and paste it in Settings → API URL
  6. In Settings, click Run Setup to create the required sheets
